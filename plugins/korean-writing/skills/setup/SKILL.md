# 한국어 문체 전역 설정

사용자가 명시적으로 지정하거나 한국어 문체 개선이 작업에 필요하다고 판단할 때만
`korean-writing:style`을 사용하도록 Codex 전역 지침의 작은 블록을 관리한다. 한국어로 답변한다는
이유만으로 호출하게 만들지 않는다. 설치 스크립트로 설치한 스킬 이름은 `korean-writing-style`,
이 setup의 이름은 `korean-writing-setup`이다. 본문은 모든 배포 채널에서 하나를 사용한다.

## 대상과 요청을 확인한다

- 기본 대상은 Codex다. 다른 도구의 설정을 요청했다면 Codex 파일에 대신 쓰지 말고 해당
  도구가 읽는 전역 지침 위치를 먼저 확인한다. 아래 스크립트는 Codex 전용이다.
- 설정·갱신 요청이면 실제로 반영한다. 사용법 설명이나 상태 확인 요청에서는 파일을 쓰지
  않는다. 현재 요청과 세션에 이미 주어진 권한을 따르며, 별도의 확인 절차를 추가하지 않는다.
- 상세 문체 규칙은 style 스킬에 남긴다. 전역 파일에 원본 룰북을 복사하거나, 현재 기기의
  절대 경로·플러그인 캐시 버전을 고정하지 않는다.

## 스크립트를 실행한다

제공된 이 `SKILL.md`의 실제 경로를 기준으로 `scripts/setup_global.py`를 찾는다. cwd에서
경로를 추측하지 않는다. Python 3 표준 라이브러리만 사용한다.

1. 사용 가능한 스킬 목록에서 `korean-writing:style` 또는 `korean-writing-style`을 확인한다.
   스크립트도 같은 번들의 style 파일을 검사한다. 서로 다른 위치에 설치되어 있으면 목록에서
   확인한 style의 `SKILL.md` 경로를 `--style-skill`로 전달한다. 없으면 설치가 필요한 이유를
   알려주고 전역 지침은 쓰지 않는다. 제거에는 style이 없어도 된다.
2. 설정 요청이면 아래를 실행한다. 설정 전 미리보기가 필요하면 `--dry-run`을 붙인다.

   ```bash
   python3 "<이 스킬 디렉터리>/scripts/setup_global.py"
   ```

   기본으로 `CODEX_HOME` 또는 `~/.codex`를 사용한다. 사용자 지정 프로필은 `--codex-home`
   인자로 전달한다. 비어 있지 않은 `AGENTS.override.md`가 있으면 그 파일이 활성 전역 지침이므로
   거기에 반영하고, 아니면 `AGENTS.md`에 반영한다.
3. 상태 확인에는 `--check`, 이 스킬의 전역 적용만 해제할 때는 `--remove`를 사용한다. 문체
   스킬 자체를 삭제하거나 다른 지침을 고치지 않는다.
4. 설정·갱신 뒤 `--check`로 활성 파일과 관리 블록을 확인한다. 제거 뒤에는 제거된 내용을
   확인한다. 스크립트 실패를 성공으로 보고하거나 수동 덮어쓰기로 우회하지 않는다.

스크립트는 `soohan-skills:korean-writing` 주석 사이만 교체한다. 기존 내용·심링크·파일 권한을
보존하며, 실제 변경이 있을 때만 기존 파일의 백업을 남긴다. 반복 실행해도 블록이 중복되지
않는다. 짝이 맞지 않거나 중복된 주석은 자동으로 추측해 고치지 않고 오류로 알린다.

## 결과를 보고한다

변경한 활성 파일, 추가·갱신·이미 적용됨·해제 중 어떤 결과인지, 백업 경로를 짧게 알린다.
전역 파일 전체를 출력하지 않는다. 새 Codex 세션부터 변경한 사용 조건이 반영된다고 안내한다.
스킬 설치 자체는 전역 설정을 변경하지 않으며, 새 기기에서는
설치 후 이 setup을 실행한다. 업데이트 후 다시 실행하면 관리 블록도 최신 내용으로 갱신된다.

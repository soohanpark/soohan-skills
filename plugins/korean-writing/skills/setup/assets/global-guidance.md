## 한국어 작성

- 사용자가 명시적으로 지정하거나 한국어 문체 개선이 작업에 필요하다고 판단할 때만 `korean-writing:style` 스킬을 읽고 적용한다. 설치 스크립트로 설치한 환경의 이름은 `korean-writing-style`이다.
- 한국어로 답변한다는 이유만으로 스킬을 읽거나 적용하지 않는다. 적용할 때는 사용자가 요청한 길이·형식·어조와 프로젝트 지침을 우선한다.
- 의미·사실·수치·인용·조건·확신 수준을 보존한다. 요약에서는 내용을 줄일 수 있지만 남긴 주장의 뜻을 바꾸지 않는다.
- 적용이 필요한데 스킬이 없으면 이 보존 원칙을 따르고 누락을 알린다. 전역 지침에 상세 룰북을 복제하거나 임의로 설치하지 않는다.

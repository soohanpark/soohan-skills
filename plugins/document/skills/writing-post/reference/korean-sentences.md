# 한국어 문장 교정표

퇴고 3차에서 문장마다 대보는 표. 규칙은 하나다 — 한 글자를 더 썼으면 문장이 정확해지거나
풍부해져야 하고, 어색해졌으면 뺀다. 번역투는 뜻이 안 통하는 게 아니라 읽는 속도를 떨어뜨린다.

| 걸리는 것 | 고치기 |
| --- | --- |
| 적·의·것·들 | 빼도 뜻이 남으면 뺀다. "눈으로 덮여 있는 마을" → "눈으로 덮인 마을" |
| ~에 대한 | 동사로 푼다. "노력에 대한 대가" → "노력에 걸맞은 대가" |
| ~에 의한, ~로 인한 | "따른", "때문에"로. "고장에 의한 오류로 인해 발생한 사고" → "고장에 따른 오동작 때문에 발생한 사고" |
| 겹친 조사 (~로의, ~에게로) | 하나만 남긴다. "세계로의 진입이 시작되었다" → "세계로 진입하기 시작했다" |
| ~로부터 | 에게·와·에서 중 맞는 것으로. "친구로부터 받았다" → "친구에게 받았다" |
| 무생물 + ~에게 | 무생물은 ~에. "미국에게 설명했다" → "미국에 설명했다" |
| 겹친 피동·사동 | 이미 피동인 동사에 -이-, -어지-를 겹치지 않는다. "나뉘어진" → "나뉜", "잊혀지지" → "잊히지" |
| ~ㄹ 수 있는 | 가능성이 요점이 아니면 뺀다. "느낄 수 있었던 불안" → "느낀 불안" |
| 그 어떤, 그 어느 | 하나만. "그 어떤 조치도" → "아무 조치도" |
| ~는가를 | 연결은 ~는지. "어떻게 전개되는가를" → "어떻게 전개되는지" |
| ~기 시작하다 | 시작점이 없는 심리 변화에는 붙이지 않는다. "놀라기 시작했다" → "놀랐다" |
| ~들 중 하나 | 당연한 것은 늘이지 않는다. "전형적인 독일 여자들 중 한 사람" → "전형적인 독일 여자" |
| ~했어야 했다 | 시제 하나로. → "~해야 했다" |
| 한자어 | 쉬운 우리말이 있으면 그것으로 |
| ~되어진다, ~에 의해 | 능동으로 되돌린다. 행위자가 있으면 행위자를 주어로 |
